Burrow

Your own VPN, on your own cloud account. No subscription.

  1. 1 Create a free AWS account

    Skip this if you already have one. AWS asks for a card, but Burrow only ever creates one small server that you can destroy whenever you like.

  2. 2 Make a user just for Burrow

    Don't use your main login. This creates a restricted user that can only touch Lightsail, so a leaked key can't reach the rest of your account.

    • User name: burrow
    • Click Next
    • Choose Attach policies directly
    • Search for AmazonLightsailFullAccess and tick it
    • Click Next, then Create user

  3. 3 Create an access key

    This is the part Burrow needs. It is not your password.

    • Click the burrow user you just made
    • Open the Security credentials tab
    • Scroll to Access keys → Create access key
    • Choose Command Line Interface (CLI), tick the confirmation, Next
    • Create access key

    The secret is shown once. If you close that page without copying it, delete the key and make another — it cannot be recovered.

  4. 4 Paste them here

    Stored in your system keychain, never in a file. Burrow talks straight to AWS — there is no Burrow server, and your keys never leave this machine.
